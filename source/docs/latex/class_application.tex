\doxysubsection{Detailed Description}
Main application class that manages the travel agency system. 

The \doxylink{class_application}{Application} class is the main entry point for the travel agency management system. It initializes all components, manages dependencies, and controls the application lifecycle. This class follows the Singleton pattern to ensure only one instance exists.
