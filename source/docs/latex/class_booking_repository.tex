\doxysubsection{Detailed Description}
Implementation of \doxylink{class_i_booking_repository}{IBooking\+Repository} for CSV file storage. 

This class provides an implementation of the \doxylink{class_i_booking_repository}{IBooking\+Repository} interface that uses CSV files for persistent storage of booking data. It handles all CRUD operations for \doxylink{class_booking}{Booking} objects, translating between object and CSV formats.
