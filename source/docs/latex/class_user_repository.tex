\doxysubsection{Detailed Description}
Implementation of \doxylink{class_i_user_repository}{IUser\+Repository} for CSV file storage. 

This class provides an implementation of the \doxylink{class_i_user_repository}{IUser\+Repository} interface that uses CSV files for persistent storage of user data. It handles all CRUD operations for \doxylink{class_user}{User} objects, translating between object and CSV formats.
